## Passed model checks

The runtime recipe audit checks the selected snapshot’s quantity records, references, variant allergen declarations, method requirements, package consistency, date windows and storage declarations. The audit returns structured findings, severity, identifiers and a snapshot fingerprint. An unresolved package or product gets a specific finding. Availability and whole-batch assignment are evaluated separately by the shared planner.

The regression suite checks each of the 20 methods with a real household, removes a required tool to verify blocking, and compares each method’s collection list with the full household’s scaled ingredient quantities. For sealed lots it checks exact whole-package counts. Further tests exercise conflicting package metadata, unknown required declarations and H01’s two-lot access. The independent whole-week ledger check also reconciled every seed and received-plan collection box with the recipe allocations and the inventory totals.

The instruction corrections and packaging descriptions change neither the model portions nor the seeded allocation constraints. On the checked fixture, 241 of 378 portions were allocated initially, 249 after receiving the Monday offer, and 253 after also supplying H01 with a can opener.
