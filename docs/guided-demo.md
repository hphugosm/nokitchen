# Guided demo

Start in **Food bank → Weekly plan → Start guided demo**. All steps use the same application commands as the ordinary scenario, in a separate in-memory session. The reference week starts Monday, 2026-11-23.

1. **Start with the household week.** Inspect an assigned meal. Read its household-sized batch, method and the family counts for breakfast and main meals.
2. **Paste a donor offer.** Select **Paste donor offer**, choose **Packaged chickpeas**, and select **Parse offer**. The original donor text identifies twelve sealed pouches of 200 g edible contents and two ISO dates. Extraction saves a proposal.
3. **Review the product and dates.** Use the synthetic product label and the bank’s stated window to confirm ambient storage before opening, refrigeration after opening and availability Monday through Sunday. Select **Save edits** and **Mark reviewed**. For another donor message, verify and enter its own facts.
4. **Preview the delivery.** Select **Preview impact**. Inspect the *If received as entered* comparison, household effects and exact collection quantities. The tour starts with an unapproved draft and therefore recommends the coverage-oriented alternative.
5. **Record the actual receipt.** Use the reviewed values for this walkthrough. Select **Confirm received** and **Recalculate**. In the ordinary workspace, a different actual amount or date requires confirmation before receipt and produces a new calculation.
6. **Improve variety.** Select **Improve variety**. Review the assigned meals whose recipes changed and portion counts, then inspect the family frequencies separately for breakfast and main meals.
7. **Approve and inspect the box.** Approve the draft, open an assigned household meal and inspect its collection boxes. **Finish tour** returns to the original workspace.

Back restores a step checkpoint. Restart starts a fresh isolated week. Exit and reload discard the tour. Ordinary inventory, approvals and saved offers stay in their own session. [Measured results](results-1.3.1.md)
