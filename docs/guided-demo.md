# Guided demo

Start in **Food bank → Weekly plan → Start guided demo**, or use the guided-demo navigation entry. Each step uses the ordinary application commands in a separate in-memory week starting Monday, 23 November 2026.

1. **Inspect the draft meal plan.** The food-bank workspace opens a fresh draft. Select **Inspect assigned meal** to inspect its portions, preparation method and collection. The tour starts with no approved household plan.
2. **Paste a donor offer.** Select **Paste donor offer** if needed, then **Packaged chickpeas** and **Parse offer**. The offer contains twelve sealed pouches with 200 g edible contents each.
3. **Review the product and dates.** Verify the synthetic label and model window. Select **Confirm the example product details**, **Save edits** and **Mark reviewed**.
4. **Preview the delivery.** Select **Preview impact** to inspect hypothetical changes. The tour’s unapproved baseline initially favors the coverage alternative. Inventory is unchanged.
5. **Record the actual receipt.** Keep all twelve reviewed pouches. Select **Confirm received** and **Recalculate** to inspect meal and box changes from actual stock.
6. **Improve variety.** Select **Improve variety**. Compare the recipe choices, fixed slots and portions. Inspect **Meal types and weekly meals** where available.
7. **Approve and inspect the box.** Select **Approve plan**, then **Inspect assigned meal** and **Open collection boxes** in the household view. Finish returns to the ordinary workspace.

**Back** restores the previous step checkpoint. **Restart** opens a fresh isolated draft. **Exit**, **Finish tour** and reload discard the tour. The ordinary workspace keeps its inventory, offers and approval. The timed recording uses an already approved ordinary week so it can show the protection of promised meals.
